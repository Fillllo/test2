# Team Calendar Application

Example project with a Vue 3 + Vuetify frontend and a Spring Boot 3.5 backend using PostgreSQL.
The frontend displays a monthly calendar where days with events are highlighted.

## Structure

- `backend` – Spring Boot project providing REST API for events.
- `frontend` – Vue application displaying calendar events.

## Running

Follow the instructions in `backend/README.md` and `frontend/README.md` to run each part of the application.
